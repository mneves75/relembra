# Security policy

## Supported versions

relembra is in beta. Security fixes go to `main` and ship in the next beta release; only the
latest beta on npm (`relembra@beta`) and on GitHub Releases is supported.

## Reporting a vulnerability

Report it privately through GitHub:
[open a security advisory](https://github.com/mneves75/relembra/security/advisories/new). Never
put it in a public issue, pull request, discussion or commit. Include the affected version or
commit, the steps to reproduce and the impact.
